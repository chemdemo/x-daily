# articles

人工存档的优质长文（尤其是 X / Twitter 长文等通用 agent 不易抓取的内容）。

## 怎么放

- 一文件一文，建议命名：`YYYY-MM-DD-short-slug.md` 或 `YYYY-MM-DD-author-title.md`
- 正文尽量包含：标题、作者、原文链接、抓取/保存日期、全文或关键摘录
- 可直接粘贴英文原文；日报生成时会做结构化拆解与翻译

## 和 digests 的关系

- `digests/`：每日自动生成的深度日报
- `articles/`：你不定期投喂的原材料；X-daily 跑的时候会优先参考这里尚未消化过的存档
