# x-daily

每日归档：harness / graph / loop 工程相关长文深度日报。

由 Grok Bot 助手 `x` 的例行任务 **X-daily**（每天 10:00 Asia/Shanghai）自动写入。

## 结构

```
digests/YYYY-MM-DD.md   # 每日深度日报
articles/               # 人工投喂的优质长文存档（尤其是 X 长文）
```

- 日报主体：0–10 篇长文深度拆解（背景、论点、方法、启示、局限；原文关键段 + 中文翻译）
- 推文仅作补充线索
- `articles/` 里的新文会作为次日（或当次）日报的优先原材料
